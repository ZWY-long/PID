# 自整定验证记录（2026-10-20）

## 已完成

- 运行的是交付包内实际C代码，使用官方TinyCC 0.9.27 Windows x64便携版，`-std=c89 -Wall -Werror`，三组均exit 0。
- 自整定29项：默认与非法配置、NaN、空指针、实际输出量化、PI/PID系数及秒制单位、候选撤销、取消、联锁、缺帧、执行器确认、输入量程、稳定等待/半周期/整轮超时、慢漂移、振幅与周期门槛、增益范围、时间倒退/32位自然回绕、多实例隔离。
- 验收工具13项：通过、联锁撤销、超调、无样本、倒退、回绕、均值/合格比例失败、重复毫秒样本、实例隔离、非法配置、波动测量。
- 接入示例16项：实验启动、真实输出、联锁停热、量程拒绝、候选试跑、旧配置保留、PID间隔上限、失败回退、试跑通过及通过后的失联保护。
- 一阶加纯滞后热对象仿真：环境21℃、过程增益1℃/百分点、时间常数80秒、纯滞后10秒。默认配置在仿真808秒产生PI候选Kp约1.638023、Ki约0.03276047、Kd=0；周期50秒、温度半振幅1.24368℃。这些是测试对象的结果，不是现场推荐参数。
- Keil C51 V9.60.7.0以LARGE内存模型分别编译自整定入口及完整接入示例：均0错误、0警告。说明与源码均采用实际交付编码重新编译验证。
- 原桌面通用PID核心保持字节一致。

## 限制

共58项通过不代表任意物理对象均可被正确辨识或稳定控制。继电滞回、生产滤波、非线性、负载变化和热耦合都会影响结果。仿真没有覆盖所有传感器、执行器及现场异常。

没有执行C51机器码、没有完整目标工程链接/时序测试、没有烧写或实机整定，也未改现场参数。原模块10/0.05/20是原设备验证参数，本次新增模块只产生新项目候选。必须在项目允许试验范围内进行实机验证。

## 复验

`python 验证测试/运行自整定测试.py --compiler C:/path/to/tcc.exe`

便携编译器不作为PID运行依赖，不随本模块复制到桌面。Keil项目只加入一个实现编译单元。完整日志位于验证测试目录。
